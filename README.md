# OOBE Ace Agent

This project is an Autonomous Capital Agent built for the Steve Capital ecosystem (OOBE Protocol). It integrates with the Ace Data Cloud MCP to research market sentiment before executing trading strategies.

## Features
- Connects to Ace Data Cloud API (using `gpt-4o-mini`) to fetch market insights.
- Simulates trade execution based on AI analysis.
- Built with Python and Requests.

## How to run
1. Clone this repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Set your Ace API key in a `.env` file or environment variable (`ACE_API_KEY`).
4. Run the script: `python main.py`
